🗂 Cartella condivisa di Jarvis
Struttura
Un'unica cartella protetta da password raccoglie tutto ciò che Jarvis crea, in sottocartelle numerate. I nomi iniziano con la data in ordine inverso (es. 20261002_lista-della-spesa.txt), così l'ordine alfabetico è anche quello cronologico. Da Windows: Esplora file → barra dell'indirizzo → incolli l'indirizzo qui sopra e inserisca utente e password (spunti «Memorizza credenziali»). Per un'unità fissa: Questo PC → «Connetti unità di rete» → stesso indirizzo, con «Connetti con credenziali diverse». Se Windows risponde che sono già in uso credenziali diverse per lo stesso server, scolleghi prima le altre connessioni (net use \\IP /delete) e riprovi. Per cambiare la password: Funzionalità › Condivisioni di rete.
