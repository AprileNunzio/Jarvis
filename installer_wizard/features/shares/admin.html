🗂 Condivisioni di rete
Cartelle
Da Windows: Esplora file → barra dell'indirizzo → incolli l'indirizzo di una cartella (pulsante «Copia» accanto), per esempio \\IP\condivisa: il nome della cartella va subito dopo l'IP, senza altre cartelle in mezzo. Per un'unità fissa: Questo PC → «Connetti unità di rete» → stesso indirizzo; per «memoria-jarvis» spunti «Connetti con credenziali diverse» e usi utente e password qui sopra (con «Memorizza credenziali»). Se Windows risponde che sono già in uso credenziali diverse per lo stesso server, scolleghi prima le altre unità di quel server (net use \\IP /delete) e riprovi. Per cambiare la password: Funzionalità › Condivisioni di rete.
